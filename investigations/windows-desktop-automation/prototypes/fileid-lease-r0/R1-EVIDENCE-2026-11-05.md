## Supported root cause

Original Program.cs:317 calls Console.In.ReadLineAsync() **before** its Task.WhenAny(... Task.Delay(500)) check. Official [Microsoft .NET 10 Console.In documentation](https://learn.microsoft.com/en-us/dotnet/api/system.console.in?view=net-10.0) confirms Console.In reads execute **synchronously, including ReadLineAsync**. Microsoft runtime [SyncTextReader implementation](https://source.dot.net/System.Console/System/IO/SyncTextReader.cs.html) returns Task.FromResult(ReadLine()), which blocks if no input. Thus B02 no-ACK blocks before starting the 500ms timeout; B01 passes because ACK unblocks it. Node's readyChild lines 73–90 ultimately kills only its owned disposable helper on 5500ms and reports OWNED_CHILD_DEADLINE. This is source-and-official-documentation-supported; no native process stack was captured.
